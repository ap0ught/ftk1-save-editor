FTK1 Save Editor

A local Flask web app for editing For The King (FTK1) save files (.run) and player.db.

Features

  • Unpack and repack gzip UTF-16 JSON .run saves.
  • Edit game info, character vitals, augmented stats, status, and inventory.
  • Web UI with inventory-style gear slots and backpack item editing.
  • Consumable +10 buttons.
  • Edit player.db: stats, achievements, unlock all lore.
  • Backup on overwrite (.bak).

Run locally

git clone https://github.com/ap0ught/ftk1-save-editor.git
cd ftk1-save-editor
python -m pip install -r requirements.txt
python app.py

Then open http://127.0.0.1:5000.

Note: this is a Python/Flask backend tool, so it runs locally. GitHub Pages hosts the static documentation; it cannot run the Python app itself.

Verify an edited save

python3 verify_save.py /path/to/edited.run
